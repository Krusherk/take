# TAKE V0 Attack Registry

| Pattern | V0 treatment | Allocation effect |
| --- | --- | --- |
| Known canonical self-nomination | Objective invalidity | Rejected |
| Second TAKE from one canonical giver | Objective invalidity | Rejected |
| Invalid or absent eligibility proof | Objective invalidity | Rejected |
| Direct reciprocity | Behavioral observation | None |
| Three/four-person cycle | Behavioral observation | None |
| Temporal burst | Behavioral observation | None |
| Repeated giver or recipient set | Deferred/observational | None |
| Cross-campaign coalition | Deferred/observational | None |
| Candidate splitting | Simulation and research measurement | None in V0 |
| Eligible real-human coordination | Residual mechanism risk | None unless objectively invalid |
| Sybil identities that pass eligibility | Residual identity-layer risk | Each valid canonical giver contributes one unit |

The registry distinguishes detectable patterns from conclusions about fraud. Community density is not itself evidence of manipulation.
